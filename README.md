## 01 — ABOUT

**Subnautica: Above Celsius** is a fan-made modification for **Subnautica**.

The project is currently in development and has **not been released**.

For now, the details of what *Above Celsius* actually is are being kept private. We aren't going to spoil the experience before it's ready.

More information will be revealed through future development updates and announcements.

## 05 — MODDING REQUIREMENTS

Installation requirements will be confirmed when the mod is released.

Development and testing currently make use of established Subnautica modding tools and frameworks.

### BepInEx

A mod loading framework commonly used for Subnautica modifications.

[View BepInEx on Nexus Mods](https://www.nexusmods.com/subnautica/mods/1108)

### Nautilus

A framework and library providing tools for Subnautica mod development.

- [Nautilus GitHub](https://github.com/SubnauticaModding/Nautilus)
